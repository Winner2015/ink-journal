# 松涛雪

京郊临行赠兄

缓步时歇，

凝眉处、袂分紫陌，

芳草蓁蓁。

忍望尘消影远，

暑空蝉噪，

足下起雷音。

断水蹙萍，

孤峰敛黛，

河柳荡波心。

九转轺辙、驰丘谷，

没京门。　　

　　

渺千间广厦，

物尽豪奢，

自古拒纳蓬蒿人。

别来经年重到，

料应是，

策马报捷闻。

告梓桑，

行游辇下，

栖寄浮身。

并躯肩，

共泛沧浪

笑傲风云。

旬暇每聚首，

把酒叙天伦。

#  满庭芳三首

## 一

露嵌重茵，

花妆叠翠，

近薄几处鸣蝉。

晚凉新树，

寂寞锁寒烟。

可叹翠禽舌巧，

殷勤意，

空惹人嫌。

红尘事、闲愁多少，

携酒到尊前。



无言，

谁念我，

沈腰如是，

罗带长宽。

怕个中情味，

一日频添。

休道月华堪赏，

凭栏久，

岂为银蟾。

奈何是，

凌波倩影，

不肯教人眠。



## 二

梅韵初收，

桃妆未靓，

正恨春讯无凭。

怯寒娇燕，

执意负东风。

尽日倾杯殢酒，

图一醉，

试遣愚衷。

求凰曲、寸心堪表，

未敢赋琴筝。

　　

相逢，

难忘处，

眉颦柳竖，

目眄波横。

悔偷撷红豆，

错许三生。

永夜恹恹迟睡，

怕梦里，

又睹娉婷。

倚楼望，

微云淡月，

一带远山暝。

 

## 三

红藕香残，

碧梧色老，

故园满目清秋。

蝉声蛩语，

句句谱新愁。

犹记当年花下，

寻倩影，

几度回眸。

西风里、一沟寒水，

寂寞向东流。

　　

悠悠，

念旧事，

高唐云散，

楚殿歌休。

忆魂销驿尾，

肠断桥头。

悲恨一时竟起，

情如海，

乱绪难收。

销凝处，

斜阳立尽，

无语下秦楼。

# 踏莎行 毕业送别

四时风物，莫盛于仲夏，人情之苦，莫重于离愁。而良辰美景，陡遇离愁，赏心乐事尽作幽幽之叹。三年同窗，风雨相随。画间柳下，粉蝶同捕;案上窗前，奇文共赏。满庭芳草，俱为旧时相识；触目朱颜，皆是陈年故交。一旦离别，能不感慨系之？始信江郎之“黯然销魂者，唯别而已矣”不吾欺也！“从今各是异乡人，相见更无因”、“休休，这会去也，千万遍阳关，也则难留”，皆摧人心肝之句也。千里之外，或可从驿寄梅花，鱼传尺素之故事，然世事百转，未可逆料。柔情似水，佳期如梦。幸有一轮明月无山水之隔也。



暮鸟啼愁，

残阳泣血，

魂牵碧柳蝉声咽。

一庭芳草正情浓，

哀筝偏奏阳关阕。



只影寻花，

孤舟钓雪，

天涯冷落穷思夜。

风尘如若阻佳期，

君心且寄云间月。

# 浪淘沙 效纳兰体

负手立霜天，

满目新颜，

重寻旧事料应难。

唯有楼前花共柳，

犹似当年。



尘信阻关山，

梦里婵娟，

绸缪心事不须瞒。

细数平生多少恨，

都在眉间。

# 满庭芳 冬夜书怀

残月涂霜，

疏星射雪，

冷浸表里乾坤。

天狼明灭，

隐隐度微云。

借我凌霄一鹤，

临玉阕，

俱告灵君。

倾银汗、三千白浪，

雨落荡妖氛！



辕门，

旌纛矗，

貔貅横列，

铁甲威森。

斥奸贼何教，

肝胆蒙尘！

欲仗青锋长剑，

捣东海，

尽斩蛟鲲。

再诉与，

怒涛万顷，

把酒祭忠魂！

# 潇湘夜雨

泪浥莲心，

愁凝鸳背，

蓼花难缀余红。

平湖自碧似情浓。

偏更有，

箫吟断续，

遏纤云，

频递悲声。

休提甚、

青竹镌字，

墨楮剖衷。

百结心事，

千般滋味，

分付西风。

叹沈园堪访，

何觅芳踪。

应笑我，

江湖浪客，

痴绝处，

也信鸾盟。

邀唐、陆，

携将旧恨，

来诉梦魂中。
