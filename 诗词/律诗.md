# 中秋感怀

旅舍清秋夜，窗白露满庭。

菊魂依瘦草，桂魄澹疏桐。

酒淡乡思厚，衣薄客恨浓。

云楼遮望眼，倚立对寒蛩。

# 出塞

大漠高风起，千层铁甲寒。

暝云压故垒，晓月度残关。

目尽河沙血，途穷塞草烟。

危城闻鼓角，跨马抚龙渊。

# 冬日村居

暮尽斜晖里，黄灯欲上时。

烟升浮冻树，雀落振寒枝。

劲柏擎苍雪，修竹倚褐石。

悠然心会处，静晚独归迟。

# 回乡祭祖

常为异客恋乡尘，四海游学弃眷亲。

未晓族耆余几辈，年年陌上拜新坟。

# 秋夜

人眠尘籁静，秋夜转苍茫。

薄雾黄灯远，虫鸣碧野荒。

萍风移月影，草露聚流光。

但恨良辰短，谁言曲陌长。

# 山居四首

## 一

日落寒山远，樵歌挽暮云。

霜枫茅舍外，野老待归人。

## 二

鹤影翔空谷，秋溪和水谣。

闲夫垂钓罢，款款度石桥。

## 三

春山一夜雨，晨起事桑麻。

此日独归早，东篱种晚花。

## 四

月冷千山雪，白屋没广明。

和衣灯下卧，浅味道德经。 

# 春游正定五首

## 一

圣土钟灵水育蛟，雕碑纪史列英豪。

此生不坠青云志，抖落功名会尔曹。

## 二

何人逾海唤仙夫，妙笔丹青绘锦图。

彩栋萦云飞白鹤，华屏润雨挺翠竹。

## 三

铁血衰吟贯史篇，幸得固垒镇常山。

城头依旧陈兵甲，只为游人好古观。

## 四

遍挂桃符万户新，清溪水软漾微鳞。

冬芜未肯待归燕，已吐寒青报早春。

## 五

宝塔森然古寺幽，轻烟四起绕门楼。

金身漫殿闻痴语，应笑愚生索怨愁。

# 寄京师陈大

山林冬雪后，偶事过君家。

寂寞柴扉侧，寒梅满树花。 

# 三峡

恍若天流断，窈峡湍濑急。

危峰绝鹭影，空谷荡猿啼。

轻舟时蹈浪，远岫忽披霓。

回望惊心处，一江烟水迷。

# 初雪

此岁冬时晚，今朝遇雪惊。

飞花妆落木，舞絮动诗情。

万象出尘异，千枝入眼明。

长留一寸玉，不必盼新晴。

# 四时即事

## 春夜即事

旷苑高阁烛影深，箫歌遣恨警眠禽。

趋光弱翼投窗眼，避岸柔枝绕水心。

对月幽思云障目，临花独卧雨愁人。

怜红长恐春归早，零落残香无处寻。

## 夏夜即事

愈爱良宵厌昼长，临池小伫趁清凉。

胸沾银桂一襟雪，臂拦红莲两袖香。

处处蛩吟喧草径，斑斑竹影缀纱窗。

铜壶初断灯花落，北斗横空夜未央。

## 秋夜即事

夜静霜枝坠塔榛，秋河素浅漏滴深。

珠帘有隙筛寒影，玉镜无端惹落尘。

案上孤灯词外意，窗前月色梦中人。

红荷褪谢沉塘底， 枉向平波觅旧痕。 

## 冬夜即事

冬容惨淡苦凡心，蜡泣铜台亦有痕。

雪葬黄花秋梦远，霜欺翠柏夜寒深。

浮云落影伤尘事，瘦月窥窗吊病魂。

纵使冰溶春可待，桥边红药寄何人。

# 寄太原旧友

怀君千里外，霜色染深秋。

此日城头望，当年月下游。

相思无吕驾，适性有王舟。

遥知归雁过，应自起乡愁。

# 秋田暮归

垄上耕锄罢，独身负草还。

荒村临北麓，落日近西山。

归鸦携暮霭，陌柳带暝烟。

忘世得闲逸，长居武陵源。  

# 得中后访祖母故居

故院重归事事哀，空余树影自徘徊。

侧耳何能聆诲语，掀帘仍望就襟怀。

虽知鹤影云中去，犹盼慈容梦里来。

深惭月桂攀折晚，特秉丹书慰泉台。

# 江南

世路累儒冠，松衣泛画船。

红林生紫霭，翠鸟度青烟。

柳岸闻箫立，竹楼抱月眠。

拟驯孤山鹤，托终碧水边。

# 赠雪

垂暮临行，微雪纷扬，途中渐大。余望天而问：“雪兄下尘送余乎？”翌日至杭州，初到思乡，暮时开窗，惊见漫天皆白，乡心稍释。

回眸按辔去乡关，絮雪多情送旅颜。

又恐丝竹愁客梦，直追故友到江南。

# 省内舅归杭途中作

吾妻之舅，齐鲁伟丈夫也，身长八尺，虎背熊腰。昔年内子将归宁，置酒高会，余于席间初识舅氏。一见便觉意气相投，众客之中，独蒙青眼。倾杯纵谈，扺掌长歌，浑然无生疏之隔，大有故人重逢之乐。
倏忽两载，世事摧人。竟染沉疴，缠绵未愈。今千里登门探视，再见之时，昔日雄姿尽损，形骸骨立，不复当年壮硕模样，观之令人怆然。
于是，余有叹焉。回杭途中，成此七律，以记此别。
