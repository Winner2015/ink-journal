#  中吕 山坡羊

彩袖如霞，

笑靥如花，

风情万种俏冤家。

娇恰恰，羞答答，

掩耳拒听痴心话。

一任我辗转中宵废饭茶，

爱，也是她，

恨，也是她。


# 绝句

因惜黄叶碎，绕树蹑足行。

# 夏末

**（一）**

林寂蝉且尽，露重衰草轻。

塞北一声雁，惹得万绿惊。

（二）

寒蝉失夏韵，牧管作秋声。

每见残荷落，还思恰恰莺。

# 送兄归京

浮云郭外横，天末起长风。

为有鸿鹄志，长作万里征。

# 农家一景

寻望绿藏鸟语处，轻风迎面送香来。

# 初秋

漠漠轻寒枕簟凉，披衣疾走闭纱窗。

未知昨夜西风紧，碧柳平添几叶黄。

# 所见

子夜尤觉枕被单，一番宿雨长秋寒。

平明百妇出行早，好为诸儿送锦衫。

# 无题

友海庭遗余二句诗，乃“二月春残燕子常，姑苏城外桃花庄”，嘱余试对之。此二句似取自唐寅之《桃花诗》，然彼时余在校内，无处求证，遂以七古成之，聊以自娱。

二月春残燕子常，姑苏城外桃花庄。

波袅绿烟两岸秀，风动红霞一院香。

竹下瀹茗濯玉盏，花间煮酒倾银觞。

尺幅未尽方寸意，水榭时时理丝簧。

# 伤黛玉

只道玉金配，木石岂无缘！

啼痕牵翠袖，素怨损朱颜。

柳岸寒风烈，云霄冷月残。

终为群口误，含恨赴黄泉！

# 咏牛

足踏黄土迎风雪，背负青天追日月。

一曲苦歌难奏尽，十年薄命易消决。

# 御街行

客居处处着秋意，

厌枕被、临窗立。

远空极目雁先归，

更有秋风惊绿。

寒烟绕树，

深庭向晚，

几点摧花雨。



绕楼听遍残蛩语，

早惹乱、思千缕。

征尘何日尽消去，

再把盟约重续。

春花秋月，

举杯共赏，

长作神仙侣。

# 忆秦娥

方院静，

篱边惟有黄花盛。

黄花盛，

深宵常伴，

月下孤影。



锦衾不耐空房冷，

一帘秋色隔春梦。

隔春梦，

寒梧飞落，

渐埋幽径。

# 虞美人 寄故友

只身独向畴边立，

晴野连天碧。

冬苗尽日扮春颜，

不解柳枝憔悴正风寒。

 

日斜林外清霜路，

曾是同游处。

参商浮动各天涯，

知否近来梅树欲着花？

# 菩萨蛮 初秋

秋池冷寂芙蓉褪，

孤松隐雾凝寒翠。

长夜雨滴频，

和风凋绿林。



流馨菊正艳，

香圃残花乱。

野草半青黄，

沾衣晓露凉。

# 雨霖铃

秋空云破，

朔风凄紧，

小楼寒彻。

篱边赤蕊疏淡，

凝伫处，

一庭萧索。

日暮哀鸿断续，

屡惊天涯客。

算只有`离恨千端，

暗理红笺为无色。

 

登高念远伤情迫，

想佳人、对镜拥妆惰。

当初泪眼相嘱，

今又是、井梧零落。

永夜堆愁，

应对鸳衾抱影灯侧。

便纵洒`粉泪千行，

肯信前缘错？

# 长相思

梓叶飘，

柳叶飘。

云里无音雁字高，

暝烟笼灞桥。



枕边潮，

袖边潮。

永夜难眠对琼瑶，

倚楼吹玉箫。
